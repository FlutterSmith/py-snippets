# Project docs

How this project was planned and designed, kept for anyone who wants the reasoning behind it.

- [plan.md](plan.md): analysis of the original collection (every example executed), the license review, the architecture, the triage of all 160 upstream snippets, and a build log of where v0.1 departed from the plan.
- [design.md](design.md): the visual design. It covers the "lab notebook" idea (graph paper in light mode, a chalkboard in dark), colour and type tokens, key screens, motion and voice.
- [design-preview.html](design-preview.html): the clickable mockup that was approved before the site was built. Download it and open it in a browser.

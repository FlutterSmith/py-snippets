chunk_into_n(items, n)

Split a sequence into n lists of almost equal size. The last one may be shorter.

listsbeginnerO(n) time✓ 3 examples pass on 3.12 – 3.14

Edit the code and the examples re-run. Loads Python once (about 7 MB), then it's instant.

How it works

  • ceil(len(items) / n) gives the chunk size, rounding up so nothing is left over.
  • A range with that step marks where each chunk starts, and slicing does the rest.
  • Empty input gives an empty list, not n empty lists.

Complexity O(n) time · O(n) extra space · Edge cases raises ValueError when n < 1
